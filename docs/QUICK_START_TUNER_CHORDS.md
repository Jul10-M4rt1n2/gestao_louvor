## 🎸 Afinador Cromático

### Como Usar

1. **Acesse** `/tuner` no menu "Afinador"
2. **Clique** em "Iniciar Afinador"
3. **Permita** acesso ao microfone (quando solicitado)
4. **Toque** uma nota no seu instrumento
5. **Observe** o ponteiro e a cor:
   - 🔴 Vermelho = Muito desafinado
   - 🟡 Amarelo = Próximo
   - 🟢 Verde = Afinado!

### Informações Exibidas

- **Nota:** Nome da nota detectada (C, D, E, F, G, A, B)
- **Frequência:** Em Hertz (Hz)
- **Cents:** Desvio em centésimos de semitom (±50)
- **Indicador Visual:** Ponteiro rotativo com cores

### Referência de Afinação (Violão Padrão)

```
E4 (1ª corda) = 329.63 Hz
B3 (2ª corda) = 246.94 Hz
G3 (3ª corda) = 196.00 Hz
D3 (4ª corda) = 146.83 Hz
A2 (5ª corda) = 110.00 Hz
E2 (6ª corda) = 82.41 Hz
```

### Dicas

- Use ambiente silencioso para melhor precisão
- Toque notas individuais (não acordes)
- Aguarde o ponteiro estabilizar
- Ajuste até ficar verde (±5 cents)

## 📚 Dicionário de Acordes

### Como Usar

1. **Acesse** `/chords` no menu "Dicionário de Acordes"
2. **Navegue** pelos acordes no grid
3. **Busque** por nome (ex: "Em", "C7", "Gmaj7")
4. **Filtre** por:
   - **Tom:** C, D, E, F, G, A, B
   - **Tipo:** Major, Minor, 7, maj7, m7, sus2, sus4, dim, aug
5. **Clique** em um acorde para ver detalhes

### Entendendo os Diagramas

**Violão (6 cordas):**
```
   E A D G B E  (cordas, da mais grossa à mais fina)
   | | | | | |
1 -|-|-|-|-|-  (1ª casa)
  -|-|-|-|-|-
2 -|-●-|-|-●  (● = dedo)
  -|-|-|-|-|-
3 -●-|-●-|-|-
  -|-|-|-|-|-
```

**Símbolos:**
- **●** = Pressione com dedo (número indica qual dedo)
- **O** = Corda solta (toque sem pressionar)
- **X** = Não toque esta corda
- **Números** = Casas do braço (frets)

**Dedos:**
- **1** = Indicador
- **2** = Médio
- **3** = Anelar
- **4** = Mindinho

### Exemplos Comuns

**C Major:**
```
X   O   O
●       
  ● ●   
```
Casa 1: Dedo 1 na corda B (2ª)
Casa 2: Dedo 2 na corda D (4ª)
Casa 3: Dedo 3 na corda A (5ª)
Cordas E (1ª e 6ª): Soltas
Corda E (6ª grave): Não tocar

## 🎯 Casos de Uso

### Para Prática Individual
1. Use o **afinador** antes de começar
2. Consulte o **dicionário** para aprender novos acordes
3. Pratique transições entre acordes

### Para Ensaios
1. Todos afinam com o **afinador**
2. Líder mostra acordes pelo **dicionário**
3. Equipe visualiza as mesmas posições

### Para Aprendizado
1. **Dicionário** ensina posições corretas
2. **Afinador** desenvolve ouvido musical
3. Combinação = aprendizado completo

---

## 💡 Dicas Profissionais

### Afinador
- Afine em ambiente silencioso
- Comece pelas cordas mais graves
- Sempre verifique a afinação antes de tocar
- Temperatura afeta afinação (ajuste conforme necessário)

### Dicionário
- Memorize acordes comuns primeiro (C, G, D, Em, Am)
- Pratique transições lentamente
- Use filtros para focar em acordes de uma música
- Compare digitações alternativas

---

## 🔧 Solução de Problemas

### Afinador Não Detecta Som
- ✅ Permita acesso ao microfone
- ✅ Verifique volume do instrumento
- ✅ Reduza ruído ambiente
- ✅ Toque notas mais fortes

### Acordes Não Aparecem
- ✅ Limpe filtros
- ✅ Verifique ortografia na busca
- ✅ Recarregue a página
